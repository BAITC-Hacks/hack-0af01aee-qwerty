Учебная лекция: как устроен проект «Люмен»

В этой лекции описан условный учебный проект. Все названия, сроки и числа ниже заданы для упражнения и не являются сведениями о реальной организации.

Проект «Люмен» помогает студентам планировать повторение учебного материала. Его разработала команда «Север». Пилот проходил в течение 18 дней; в нём участвовали 36 студентов. В проекте проверяли только организацию повторения. Исследование не измеряло оценки на экзамене, поэтому по его результатам нельзя делать вывод об улучшении экзаменационных баллов.

Учебный цикл проекта состоит из трёх шагов: прочитать исходный материал, ответить на вопросы без подсказки и проверить ответ по источнику. Чтение знакомит студента с содержанием. Ответ без подсказки показывает, какую информацию студент может восстановить самостоятельно. Проверка по источнику помогает найти пропуски и исправить неточное понимание.

Команда использует термин «опорный фрагмент». Это точная цитата из исходного материала, по которой можно проверить конкретный ответ. Опорный фрагмент не заменяет объяснение: цитата показывает источник, а объяснение связывает источник с вопросом. Если подходящего фрагмента нет, вопрос исключают из учебного набора.

Для каждого студента хранится список тем, которые требуют повторения. Тема попадает в этот список после неправильного ответа или после нажатия «Повторить». Правильный ответ сам по себе не удаляет тему из списка: студент отдельно отмечает, что разобрался. Такое правило помогает не принимать случайное угадывание за устойчивое понимание.

В пилоте повторение проводили на следующий день после знакомства с материалом, затем через четыре дня и ещё раз через девять дней. Это расписание было одинаковым для всех участников. Автоматическая персонализация интервалов в пилоте не использовалась.

Команда измеряла две величины. Доля завершённых сессий — отношение завершённых сессий ко всем запланированным. Доля ответов с подтверждённым источником — отношение ответов, для которых найден опорный фрагмент, ко всем проверенным ответам. Первая величина описывает участие студентов, вторая — проверяемость учебных материалов.

В начале пилота за неделю завершили 42 из 60 запланированных сессий. К концу пилота за неделю завершили 51 из 60 сессий. Эти наблюдения описывают только данный учебный пилот: контрольной группы не было, поэтому изменение нельзя уверенно объяснить только применением проекта.

Основной вывод лекции: полезный учебный материал должен помогать вспомнить информацию и давать возможность проверить её по исходному тексту. Проверяемость источника и качество обучения — связанные, но разные характеристики; наличие цитаты само по себе не доказывает правильность любого сделанного вывода.
